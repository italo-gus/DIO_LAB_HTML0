1. HTML   <voltar

É uma linguagem escrita e formal que especifica um conjunto de regras usadas para escrita de arquivo com extensão html (há outras), onde o arquivo lido e interpretado pelo navegador para montar em tela o website. Onde os arquivos (Arquivos Estáticos html, CSS, Javascript, Imagens e outros ) são armazenados nos computadores servidores Web e através da internet o computador cliente acessa o(s) arquivo(s), onde o navegador armazena o(s) arquivo(s) no computador cliente para não haver trafego inútil.

  • Não é uma linguagem de programação
  • Html é uma linguagem de marcação
  • Textos delimitados por nomes que o navegador consegue interpretar – tag. Cada nome deste delimitador tem uma função e comportamento específico.
  • Semelhante ao CSV que também é um arquivo de marcação
  • Devido ao uso de diversos tipos de equipamento/dispositivos para acesso com diferentes resoluções, deve ser considerado na criação de websites:
    • Design Responsivo ou Responsividade
    • Compatibilidade entre Navegadore (Browsers) Boas práticas e Testes

2.8 Listas ordenadas e não ordenadas   <voltar

  • <ol> lista ordenada (autonumeração)
    • <ol type="1"> Os itens da lista serão numerados com números (padrão)
    • <ol type="A"> Os itens da lista serão numerados com letras maiúsculas
    • <ol type="a"> Os itens da lista serão numerados com letras minúsculas
    • <ol type="I"> Os ​​itens da lista serão numerados com algarismos romanos maiúsculos
    • <ol type="i"> Os itens da lista serão numerados com algarismos romanos minúsculos
  • <ul> lista não ordenada (marcadores)
  • <li> Item da lista
  • <dl> lista de descrição.
  • <dt>termo de descrição.
  • <dd> para descrição do termo
